# Hempon Group — Blank Canvas Landing Page

A from-scratch landing page built on the stripped Hempon playground.

## Direction
- Dark editorial / technical visual language
- Oversized typography and asymmetric composition
- Motion-driven navigation and section reveals
- Interactive R3F hero core
- Lenis smooth scrolling
- Magnetic CTA interaction
- Real Hempon project imagery
- Responsive pricing/process layouts
- Reduced-motion support

## Run

```bash
npm install
npm run dev
```
