# Hempon Group — Blank Canvas Landing Page

A polished marketing landing page for Hempon Group built from a stripped-down starter and tailored to the brand’s editorial, technical visual style.

## Overview
This project creates a premium one-page experience for a digital products studio, combining:
- dark, high-contrast editorial design
- oversized typography and asymmetrical composition
- motion-led storytelling and section reveals
- a custom hero collage with product imagery and brand monogram
- responsive pricing, process, and capability layouts
- smooth scrolling and micro-interactions for a premium feel

## Tech Stack
- Next.js
- React
- Tailwind CSS
- Framer Motion / Motion
- Lenis smooth scrolling
- Custom branded UI components

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000 in your browser.

## Notes
The site is optimized for a modern studio presentation and includes reduced-motion support for accessibility and a cleaner experience on lower-powered devices.
